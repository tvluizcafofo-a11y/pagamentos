🔑 Como criar o token no GitHub
  1. Acesse github.com/settings/tokens?type=beta
  2. Clique em Generate new token
  3. Dê um nome (ex.: Pagamentos) e escolha a expiração
  4. Em Repository access, marque Only select repositories e escolha o repositório pagamentos
  5. Em Permissions → Repository permissions → Contents, escolha Read and write
  6. Clique em Generate token e cole no campo acima

💡 Dica: crie também o arquivo dados/dividas.json no repositório, com o conteúdo exato [] (abre e fecha colchetes, sem mais nada). Isso evita o erro de "arquivo não encontrado" na primeira execução.

⚠️ Cuidados com o token
  • Ele fica guardado no armazenamento local deste navegador
  • Use apenas em dispositivos pessoais e de confiança
  • Se suspeitar de vazamento, revogue em github.com/settings/tokens e crie outro
