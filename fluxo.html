Como funciona
  1. Despesas são lidas somente do dividas.json. O app de pagamentos continua sendo o único que escreve nele.
  2. Receitas ficam no receitas.json (separado). Só este app escreve nele.
  3. GitHub tem prioridade sobre o localStorage quando configurado — garante que os status mais recentes apareçam.
  4. Se este app estiver no mesmo domínio do app de pagamentos, também tenta herdar a configuração automaticamente.
